# INC-101 - Payment Service Connection Pool Exhaustion

The payment service experienced HTTP 503 responses shortly after an
application deployment.

Logs showed connection acquisition timeouts and connection-pool exhaustion.

Investigation found that a configuration change reduced the maximum
connection-pool size. Restoring the previous configuration resolved the
issue after engineer approval.

Key lesson: compare connection-pool configuration after deployments when
503 errors coincide with database connection failures.
