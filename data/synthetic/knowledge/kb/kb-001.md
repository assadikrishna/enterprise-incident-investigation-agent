# Knowledge Base - High CPU Utilization

Sustained high CPU utilization may cause degraded response times or request failures.

Common causes include:

- inefficient application code,
- excessive request volume,
- runaway background jobs,
- large garbage collection overhead,
- resource limits that are too low.

Recommended investigation steps include reviewing CPU metrics, process-level utilization, recent deployments, and workload changes.

CPU-related incidents should be correlated with service logs and monitoring data before determining a root cause.
